# FinPilot · Interface refinement · этап 12

Основа: `main`, коммит `5e6865f` (`add financial analytics`). Этот патч изменяет только клиентскую часть. Данные, миграции, API и расчёты не меняются.

## Что изменено

- Единые токены цветов, фонов, границ, фокуса и финансовых состояний в `client/src/styles/design-system.css`.
- Спокойная светлая и тёмная темы без декоративных градиентов. Выбор сохраняется в `localStorage` под ключом `finpilot.theme`; при первом открытии используется системное предпочтение.
- Более контрастные тексты, единые размеры элементов управления, читаемые суммы и таблицы.
- Компактное мобильное меню для всех семи разделов, без горизонтального переполнения навигации.
- Видимый фокус, ссылка «Перейти к содержимому», понятные имена кнопок и поддержка `prefers-reduced-motion`.
- Цвета SVG-графика прогноза зависят от темы.

## Ручная проверка

- Открой `http://localhost:5173/` (либо порт, выданный Vite).
- Переключи тему через кнопку с луной/солнцем. Проверь все разделы и обнови страницу — выбор должен сохраниться.
- Проверь ширины 1440, 1024, 768, 390 и 320 px через DevTools. На узком экране проверь открытие и закрытие меню, переход между разделами, доступность кнопки создания операции.
- С клавиатуры пройди по странице с помощью Tab; проверь видимость фокуса. В открытой форме проверь Escape, ввод и сохранение.
- Проверь созданные операции, счета, переводы, бюджеты, регулярные операции, прогноз и аналитику. Данные должны остаться неизменными.
- В тёмной теме отдельно проверь таблицы, значения графиков и состояния ошибок/пустых данных.
- Установи в ОС уменьшенную анимацию и убедись, что интерфейс остаётся понятным.

## Дизайн-ограничения

Базовая проверка токенов контрастности была выполнена для основных сочетаний текста и поверхностей. Она **не заменяет** полноценную проверку WCAG 2.2 AA, клавиатуры, скринридеров, зума 200/400% и визуальное тестирование на реальных устройствах. Соответствие WCAG и production-readiness пока не заявляется.

При дальнейшем развитии CSS стоит поэтапно переносить оставшиеся стили отдельных страниц из `App.css` в модульные стили компонентов; в этом обновлении существующая верстка сохранена намеренно, чтобы снизить риск регрессий.
