# FinPilot

FinPilot — веб-приложение для учёта личных финансов и анализа денежных потоков.

## Возможности текущей версии

- Обзор финансов: баланс учтённых операций, месячные доходы и расходы, диаграмма за полгода.
- Создание и удаление операций, поиск, фильтры и пагинация.
- Сохранение данных в браузере и восстановление демонстрационного набора.
- Адаптивный интерфейс для компьютера и смартфона.

Данные демонстрационные, подключение к банкам не используется. Текущая версия хранит информацию локально в браузере. API и серверное хранение находятся в разработке.

## Запуск

Требуется актуальная версия Node.js и npm.

```bash
cd client
npm install
npm run dev
```

Проверка сборки и статического анализа:

```bash
npm run build
npm run lint
```

## Технологии

React, TypeScript, Vite, React Router, CSS, Lucide Icons.

## В планах

Node.js + Express API, PostgreSQL, категории и бюджеты, регулярные операции, финансовые сценарии, автоматизированные тесты и CI/CD.
