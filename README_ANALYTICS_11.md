# FinPilot — расширенная аналитика (этап 11)

## Что входит

- Страница `/analytics` и endpoint `GET /api/analytics?through=2026-10&months=6`.
- Периоды 3, 6 или 12 месяцев; сравнение с предыдущим периодом той же длины.
- Помесячная динамика доходов и расходов, категории, операции по счетам и детализация сумм.
- Доходы и расходы считаются только по записям `transactions`. Внутренние переводы исключены.
- Месяцы без операций включены в ответ с нулевыми значениями.
- Суммы в копейках, защита от выхода за диапазон безопасного целого числа.
- SQL-запросы выполняются в read-only транзакции с уровнем изоляции `REPEATABLE READ`.

## API

`GET /api/analytics?through=2026-10&months=6`

Параметры: `through` — обязательный месяц `YYYY-MM` (1900–2199), `months` — 3, 6 или 12 (по умолчанию 6). Лишние параметры и неверные значения возвращают `422`.

Ответ `data`: `period`, `current`, `previous`, `monthly`, `categories`, `accounts`. Предыдущий период сравнения не смешивается с текущими итогами.

## Ограничения

- Аналитика учитывает записанные операции, но не прогнозируемые будущие начисления. Для будущего используется `/forecast`.
- Начальные остатки счетов не считаются доходами.
- Разделение данных между пользователями и публичная авторизация ещё не реализованы: API нельзя публиковать в интернет.
- Проверки репозитория выполнены на тестовых подменах. SQL следует проверить отдельно на локальном PostgreSQL.
