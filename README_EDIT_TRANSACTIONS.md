# FinPilot — редактирование операций

Frontend использует существующий `PATCH /api/transactions/:id`.

## Изменения

- Страница «Операции»: действие «Редактировать» в строке операции.
- Общая форма добавления и редактирования с исходными значениями при редактировании.
- Запрос `PATCH` и замена операции в состоянии React только после ответа API.
- Сохраняются существующие проверки суммы, категории и даты.
- При ошибке запросов форма остаётся открытой, а введённые значения сохраняются.

## Проверка

1. Запустить PostgreSQL, backend и frontend.
2. Открыть «Операции», нажать значок карандаша у существующей записи.
3. Изменить название, сумму, тип, категорию, дату; нажать «Сохранить».
4. Проверить обновление строки, сводки и графиков.
5. Обновить браузер: изменения должны сохраниться в PostgreSQL.
6. Проверить отмену, некорректные суммы и недоступность backend во время сохранения.

До появления авторизации и изоляции пользователей API остаётся локальным.
