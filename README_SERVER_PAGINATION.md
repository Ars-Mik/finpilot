# FinPilot — серверная пагинация и финансовая сводка

## Что изменилось

- `GET /api/transactions` возвращает операции только запрошенной страницы, а также `meta.total` и `meta.totals` по всем совпавшим фильтрам.
- `GET /api/transactions/overview?month=YYYY-MM&currentMonth=YYYY-MM` возвращает баланс по всей истории операций, выбранный месяц, последние шесть месяцев, четыре крупнейшие категории расходов и пять последних операций.
- Поиск по названию и категории, тип и месяц передаются в API. Поиск выполняется с задержкой 300 мс.
- Главная панель использует отдельный запрос и не загружает всю историю операций в память браузера.
- После добавления, редактирования и удаления страницы перечитывают данные из PostgreSQL.
- Удалён старый `useTransactions.ts` с предупреждением Oxlint.
- Сброс демоданных доступен только в режиме разработки. Он по-прежнему неатомарен, применять его к важным данным нельзя.

## Применение

Распакуй архив в корень FinPilot. Удали `client/src/hooks/useTransactions.ts`, если файл ещё существует. Новых миграций и npm-пакетов не требуется.

## Проверки

В папке `server`:

```powershell
npm run build
npm test
npm audit
```

В папке `client`:

```powershell
npm run build
npm run lint
```

Запусти PostgreSQL, backend и frontend. Проверь 12+ операций, переход между страницами, фильтры, редактирование, удаление последней записи на последней странице, обновление сводки после CRUD.

## Ограничения

- PostgreSQL API всё ещё доступен только для локального применения без авторизации. Не публикуй его в интернет.
- Для выборки страниц используется `LIMIT/OFFSET`. При высокой нагрузке перейдём на cursor pagination.
- Сброс демоданных пока последовательный, не транзакционный. Для публичной версии будет отдельный безопасный деморежим.
