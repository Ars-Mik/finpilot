Проверка SQL после первого и повторного начисления (замени UUID своим реальным ID, можно получить через GET /api/recurring):

```sql
SELECT recurring_rule_id, recurring_occurrence_date, COUNT(*)
FROM transactions
WHERE recurring_rule_id IS NOT NULL
GROUP BY recurring_rule_id, recurring_occurrence_date
ORDER BY recurring_occurrence_date DESC;
```

В каждом сочетании правила/даты `COUNT(*)` должно равняться 1.

> Не проверяй массовое начисление на реальной базе: кнопка создаёт наступившие записи за последние 12 месяцев для **всех активных правил**, а не только для выбранного. Используй тестовые данные.
