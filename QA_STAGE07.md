# Проверки этапа 07

Проверено статически: все изменённые и связанные файлы TS/TSX прочитаны и не содержат синтаксических ошибок на уровне TypeScript parser. **Обычные npm run build / npm test и PostgreSQL здесь не выполнены**: в контейнере нет npm-зависимостей текущего проекта и работающей БД. Они обязательны на машине разработчика до коммита.

- Ожидается не меньше **19 тестов** (13 прежних + 5 новых API-счетов + 1 тест привязки операции к счету).
- Проверить миграцию на *существующей* БД с хотя бы 1 старой операцией; дата и сумма не должны измениться.
- Проверить SQL агрегирование с операцией на новом счете, двумя переводами и начальным остатком. Суммы отдельных счетов могут меняться, общая сумма не должна изменяться из-за переводов.
- Проверить отрицательный баланс (пока допускается), дубликаты имён счетов, перевод на свой счет (422), перевод на неизвестный счёт (404), поля вне схемы (422).
- Проверить редактор старой операции: при сохранении ее счет не должен сбрасываться.
- Перед публичным деплоем добавить аутентификацию, изоляцию данных, идемпотентность переводов и тесты с настоящим PostgreSQL.
